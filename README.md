# Mobile Price Predictor UI

A simple and interactive web application that estimates mobile phone prices based on user inputs like RAM and storage.

## Project Overview

This project is a frontend demonstration of a mobile price prediction system. It allows users to input key specifications and get an estimated price instantly.

## Features

- User input for RAM and Storage
- Instant price estimation
- Simple and clean UI
- Deployed on Vercel
